PHYSICS FORMULAS REFERENCE:
A comprehensive formulas reference is available at formulas_reference.txt. Key formulas by scenario:

projectile_motion:
- v0x = v0 * cos(theta), v0y = v0 * sin(theta)
- x = v0x * t, y = y0 + v0y * t - 0.5 * g * t^2
- t_flight = 2 * v0 * sin(theta) / g (from ground)
- Range R = v0x * t_flight
- Max height h_max = y0 + v0y^2 / (2 * g)

kinematics_1d:
- v = v0 + a * t
- x = x0 + v0 * t + 0.5 * a * t^2
- v^2 = v0^2 + 2 * a * (x - x0)
- a = 2 * d / t^2 (from rest, distance d in time t)

inclined_plane:
- a = g * sin(theta) (frictionless)
- a = g * (sin(theta) - mu_k * cos(theta)) (with kinetic friction)
- N = m * g * cos(theta)
- f_friction = mu * N
- Static holds if tan(theta) <= mu_s

collision_1d:
- Momentum: m1 * v1_i + m2 * v2_i = m1 * v1_f + m2 * v2_f
- Restitution: e = (v2_f - v1_f) / (v1_i - v2_i)
- Elastic: v1_f = (m1 - m2) / (m1 + m2) * v1_i + 2 * m2 / (m1 + m2) * v2_i
- Perfectly inelastic: v_f = (m1 * v1_i + m2 * v2_i) / (m1 + m2)

rotational_kinematics:
- omega = omega0 + alpha * t
- theta = theta0 + omega0 * t + 0.5 * alpha * t^2
- omega^2 = omega0^2 + 2 * alpha * Delta_theta
- tau = I * alpha, I = sum(m * r^2)

mass_spring:

- v = -A * omega * sin(omega * t + phi)
- a = -omega^2 * x
- E = 0.5 * k * A^2 = 0.5 * m * v_max^2

- Time series: t, theta, omega, alpha, torque (5 key frames)
  * t = [0.0, 0.0333, 0.0667, t_end/2, t_end]
  * theta = [theta0 + omega0*t + 0.5*alpha*t^2 for each t]
  * omega = [omega0 + alpha*t for each t]
  * alpha = [alpha] * 5 (constant angular acceleration from net torque)
  * torque = [net_torque] * 5 (constant net torque)
- Compute net torque: τ = Σ(r_i * F_i * sin(angle_i)) where angle_i is angle between r and F
- Compute moment of inertia I based on pivot: end pivot I = (1/3)*m*L^2, center pivot I = (1/12)*m*L^2
- Compute angular acceleration: α = τ_net / I
- Duration: given t_end from problem, or until a certain angle is reached
- Camera: position [0, 3, 8], target [0, 0, 0] (side view of rotating rod)
- Worked solution MUST include torque calculation steps and I calculation
