PHYSICS FORMULAS REFERENCE:
A comprehensive formulas reference is available at formulas_reference.txt. Key formulas by scenario:

projectile_motion:
- v0x = v0 * cos(theta), v0y = v0 * sin(theta)
- x = v0x * t, y = y0 + v0y * t - 0.5 * g * t^2
- t_flight = 2 * v0 * sin(theta) / g (from ground)
- Range R = v0x * t_flight
- Max height h_max = y0 + v0y^2 / (2 * g)

kinematics_1d:
- v = v0 + a * t
- x = x0 + v0 * t + 0.5 * a * t^2
- v^2 = v0^2 + 2 * a * (x - x0)
- a = 2 * d / t^2 (from rest, distance d in time t)

inclined_plane:
- a = g * sin(theta) (frictionless)
- a = g * (sin(theta) - mu_k * cos(theta)) (with kinetic friction)
- N = m * g * cos(theta)
- f_friction = mu * N
- Static holds if tan(theta) <= mu_s

atwood_machine (massless pulley):
- a = (m1 - m2) * g / (m1 + m2)
- T = 2 * m1 * m2 * g / (m1 + m2)

collision_1d:
- Momentum: m1 * v1_i + m2 * v2_i = m1 * v1_f + m2 * v2_f
- Restitution: e = (v2_f - v1_f) / (v1_i - v2_i)
- Elastic: v1_f = (m1 - m2) / (m1 + m2) * v1_i + 2 * m2 / (m1 + m2) * v2_i
- Perfectly inelastic: v_f = (m1 * v1_i + m2 * v2_i) / (m1 + m2)

rotational_kinematics:
- omega = omega0 + alpha * t
- theta = theta0 + omega0 * t + 0.5 * alpha * t^2
- omega^2 = omega0^2 + 2 * alpha * Delta_theta
- tau = I * alpha, I = sum(m * r^2)

mass_spring:
- omega = sqrt(k / m), T = 2 * pi * sqrt(m / k)
- x = A * cos(omega * t + phi)
- v = -A * omega * sin(omega * t + phi)
- a = -omega^2 * x
- E = 0.5 * k * A^2 = 0.5 * m * v_max^2

- Parameters: mass, angle_deg, mu_s, mu_k, g (9.8), initial_x, initial_v
- Time series: MUST include t, x, v, a, f_normal, f_friction arrays (5 key frames, backend expands to 30 FPS)
  * t = [0.0, 0.0333, 0.0667, t_end/2, t_end]
  * x = [initial_x + 0.5*a*0.0333^2, ..., initial_x + 0.5*a*t_end^2] (use calculator for each)
  * v = [initial_v + a*0.0333, ..., initial_v + a*t_end] (use calculator for each)
  * a = [a, a, a, a, a] (constant acceleration)
  * f_normal = [m*g*cos(angle_rad)] * 5 (constant)
  * f_friction = [mu_k * m*g*cos(angle_rad)] * 5 (constant)
- Determine if static friction holds or kinetic applies
- Duration: given time from problem, or until v=0 if decelerating
- Camera: position [0, 5, 10], target [0, 0, 0]
- Use angle_deg in DEGREES (e.g., 30.0). Backend converts to radians.

atwood_machine:
- Parameters: m1, m2, g (9.8), pulley_mass (0 if massless), pulley_radius
- Time series: t, y1, y2, v, a, tension (5 key frames)
  * t = [0.0, 0.0333, 0.0667, t_end/2, t_end]
  * y1 = [y1_0 + 0.5*a*t^2 for each t]
  * y2 = [y2_0 - 0.5*a*t^2 for each t] (opposite direction)
  * v = [v0 + a*t for each t]
  * a = [a, a, a, a, a]
  * tension = [2*m1*m2*g/(m1+m2)] * 5 (constant)
- Duration: until one mass hits ground
- Camera: position [0, 5, 5], target [0, 0, 0] (side view)

projectile_motion:
- Parameters: v0, angle_deg, g (9.8), initial_height
- Time series: t, x, y, vx, vy, ax=0, ay=-g (5 key frames)
  * t = [0.0, 0.0333, 0.0667, t_flight/2, t_flight]
  * x = [v0*cos(angle_rad)*t for each t]
  * y = [initial_height + v0*sin(angle_rad)*t - 0.5*g*t^2 for each t]
  * vx = [v0*cos(angle_rad)] * 5
  * vy = [v0*sin(angle_rad) - g*t for each t]
  * ax = [0] * 5
  * ay = [-g] * 5
- Duration: time of flight
- Camera: position [0, 5, 15], target [0, 2, 0]
- Use angle_deg in DEGREES (e.g., 45.0).

rotational_kinematics:
- Parameters: theta0, omega0, alpha, t_end
- INCLUDE `object_type` ("disk"|"rod"|"hoop"|"sphere") and `radius` when derivable from the problem/diagram so the scene renders the right object (default disk)
- Include `mass` when given; for torque/moment-of-inertia problems also include `I` (or compute: disk 0.5*m*r^2, hoop m*r^2, sphere 0.4*m*r^2, rod (1/12)*m*L^2 with L = 2*radius)
- Convert "rpm" to rad/s (multiply by 2*pi/60) and "revolutions" to radians (multiply by 2*pi) before putting values in parameters
- Time series: t, theta, omega, alpha (5 key frames)
  * t = [0.0, 0.0333, 0.0667, t_end/2, t_end]
  * theta = [theta0 + omega0*t + 0.5*alpha*t^2 for each t]
  * omega = [omega0 + alpha*t for each t]
  * alpha = [alpha] * 5
- Duration: given t_end (or time-to-stop for deceleration problems where omega reaches 0)
- Camera: position [0, 5, 10], target [0, 0, 0]

mass_spring:
- Parameters: mass, k, x0 (initial displacement from equilibrium), v0, g (9.8 if vertical), damping (0 if undamped)
- Time series: t, x_eq, v, a, force, ke, pe, e_total (5 key frames over ~1 period)
  * t = [0.0, T/8, T/4, T/2, T] where T = 2*pi*sqrt(m/k)
  * Use calculator with SHM equations for each key frame
- Duration: 2-3 periods
- Camera: position [0, 5, 10], target [0, 0, 0]

collision_1d:
- Parameters: m1, m2, v1_initial, v2_initial, restitution
- Time series: t, x1, x2, v1, v2, a1, a2, force (complex - two phases)
- Duration: ~1s before, collision, ~2s after
- Camera: position [0, 5, 10], target [0, 0, 0]
